# README screenshot assets

These images are used by the repository root `README.md`.

- `dashboard-overview.webp` — health, sync, resources and Ravencoin P2P traffic.
- `dashboard-controls.webp` — bandwidth controls, connection limits and history.
- `dashboard-peers-redacted.webp` — recent blocks, mempool, peers and ElectrumX clients. Peer address values are deliberately redacted before publication.
- `dashboard-status.webp` — node, ElectrumX, event timeline and backend compatibility.

The screenshots are documentation assets only and are not loaded by the running monitor.
